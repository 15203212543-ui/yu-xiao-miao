# 于小喵宠物店经营助手

面向小型宠物门店的移动端经营记录工具，适合通过手机浏览器或添加到主屏幕后使用。

在线访问：[https://15203212543-ui.github.io/yu-xiao-miao/](https://15203212543-ui.github.io/yu-xiao-miao/)

## 主要功能

- 今日工作台：查看当日预估营收、待服务数量和工作安排。
- 预约与接单：创建预约，按日、周、月、季度和年度查询订单。
- 订单处理：支持改期、取消、恢复预约和标记已服务。
- 自动入账：订单完成后自动生成收入流水，避免重复录入。
- 手动记一笔：记录宠物、主人电话、服务项目、员工、金额和支付方式。
- 语音录入：通过浏览器语音识别辅助填写记录内容。
- 经营分析：统计收入、支出、净收入、客单价和员工业绩。
- 门店设置：维护门店名称、预算和员工信息。
- 数据导出：将经营流水导出为 CSV 文件。
- PWA：支持添加到手机主屏幕和基础离线访问。

## 订单状态

```text
待服务 -> 已服务
待服务 -> 已取消
已取消 -> 恢复预约
待服务 -> 修改日期或时间
```

取消订单不会直接删除，系统会保留取消原因和操作历史，方便后续计算取消率和核对经营记录。

## 使用方式

### 手机浏览器

打开在线地址后即可使用。iPhone 建议使用 Safari，Android 建议使用 Chrome。

### 添加到主屏幕

- iPhone：Safari 打开网站，点击“分享”，选择“添加到主屏幕”。
- Android：Chrome 打开网站，点击菜单，选择“安装应用”或“添加到主屏幕”。

### 本地运行

直接打开 `index.html` 可以查看页面。为了正常使用 Service Worker、离线缓存和麦克风权限，建议通过 HTTP 服务运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 数据存储说明

当前版本使用浏览器 `localStorage` 保存数据：

- 数据仅保存在当前浏览器和当前设备。
- 两台设备之间暂时不会自动同步。
- 清除浏览器数据或卸载主屏幕应用可能造成数据丢失。
- 正式录入经营数据时，应定期导出 CSV 备份。

后续计划接入腾讯云 CloudBase，实现账号登录、云端数据库、双设备同步和自动备份。
